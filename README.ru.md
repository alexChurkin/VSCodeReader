# VSCodeReader

[English](README.md) · **Русский**

Чтение книг в VS Code во вкладке, похожей на консольный вывод. VSCodeReader использует настоящую вкладку **Terminal** с названием книги, шрифт и цвета вашего терминала, управление с клавиатуры. Иллюстрации открываются по запросу в отдельных вкладках редактора.

Текущая сборка **0.1.0** поддерживает EPUB, FictionBook, обычный текст, комиксы CBZ, HTML и Markdown. [План реализации](docs/IMPLEMENTATION_PLAN.md) · [Архитектурные решения](docs/ADR-001-terminal-reader.md).

## Поддерживаемые форматы

| Формат | Поддержка |
| --- | --- |
| EPUB 2 / EPUB 3 (`.epub`) | Оформленные заголовки и выделения, списки, адаптивные таблицы, порядок spine, оглавление nav/NCX и растровые изображения |
| FictionBook 2 (`.fb2`) | Метаданные, вложенные разделы, стихи, примечания как разделы, изображения base64; кодировки из XML, включая Windows-1251 |
| FB2.ZIP / FBZ (`.fb2.zip`, `.fbz`) | Одна или несколько книг FB2; выбор книги, если в архиве их несколько |
| Обычный текст (`.txt`) | UTF-8, UTF-16 с BOM и настраиваемая Windows-1251; длинные файлы разбиваются на части для навигации |
| HTML (`.html`, `.htm`) | Оформленные заголовки как главы, выделения, списки, адаптивные таблицы, блоки кода, локальные и base64-изображения |
| Markdown (`.md`, `.markdown`) | Оформленные заголовки ATX/Setext, выделения, списки/задачи/адаптивные таблицы GFM, блоки кода и изображения |
| Comic Book ZIP (`.cbz`) | Растровые страницы в естественном порядке имён (`page2` перед `page10`); клавиша `i` открывает текущую страницу |

Обычные `.zip` не считаются книгами. PDF и MOBI/AZW3 не поддерживаются. EPUB с фиксированной вёрсткой, DRM и мультимедиа не входят в эту версию.

## Запуск

1. [Скачайте актуальный VSIX из GitHub Releases](https://github.com/alexChurkin/VSCodeReader/releases/latest/download/vscode-reader-0.1.0.vsix) и установите через **Extensions: Install from VSIX…**.
2. Нажмите **значок книги** на левой панели Activity Bar: откроется **Reader → Library**.
3. Нажмите **Open book…** и выберите файл. Для продолжения позже используйте **Continue reading**.

После успешных проверок `main` автоматически обновляется единственный [GitHub Release 0.1.0](https://github.com/alexChurkin/VSCodeReader/releases/tag/v0.1.0), его VSIX и контрольная сумма SHA-256. В названии релиза указан текущий Git SHA из 12 символов, например `VSCodeReader 0.1.0 · code abc123def456`, а в описании — ссылка на полный коммит. Версия расширения и ссылка скачивания остаются постоянными.

Версия остаётся **0.1.0**: каждая сборка заменяет `vscode-reader-0.1.0.vsix` и удаляет устаревшие VSIX проекта.

Для локальной сборки выполните `npm ci` и `npm run package` (Node.js 22). Для разработки нажмите F5 (`Run VSCodeReader`). Нужен VS Code 1.95.0 или новее. Для проверки есть [пример EPUB «Алисы»](samples/README.md).

Во вкладке терминала видно название книги, а в Library — список открытых книг. Настройка `vscodeReader.terminalName` позволяет задать свой шаблон с `{title}` и `{filename}`.

В контекстном меню Explorer для поддерживаемых файлов доступно действие **Open Book**. Повторное открытие той же книги возвращает её сессию. У разных книг внутри одного FB2-архива отдельные сессии и позиции чтения.

## Управление

Внизу терминала закреплена тусклая строка подсказок. Она подстраивается под ширину и показывает нужные клавиши при чтении, поиске, выборе пункта или вводе имени закладки. Справа постоянно видны текущая страница, общее число страниц и процент, например `Page 12/47 | 24.3%`. На узком терминале сокращаются подсказки и подтверждения закладок, а счётчик страниц имеет приоритет. Клавиша `?` открывает полный список действий.

Когда фокус находится в терминале читалки:

| Клавиши | Действие |
| --- | --- |
| Колёсико / тачпад | Прокрутка книги с переходом между главами |
| `v` | Зафиксировать экран и включить выделение терминала; ещё раз `v` — продолжить |
| `y` | Скопировать видимый текст без элементов интерфейса и маркеров картинок |
| `Y` | Открыть чистую главу в отдельной вкладке для выделения и копирования |
| `j` / `k`, ↓ / ↑ | Следующая / предыдущая строка |
| Space / PageDown, PageUp | Следующий / предыдущий экран с переходом между главами |
| `n` / `p` | Следующая / предыдущая глава или страница комикса |
| `g` | Оглавление |
| `/` | Поиск по книге с последним запросом, до 1000 совпадений |
| `[` / `]` | Предыдущее / следующее совпадение, по кругу |
| `c` | Очистить запрос и убрать подсветку |
| `u` / `U` | Назад / вперёд по истории переходов |
| `f`, Ctrl+клик по внутренней ссылке | Перейти к сноске или якорю; `u` возвращает к чтению |
| `b` | Быстрая закладка с подтверждением сохранения |
| `B` | Перейти к закладке |
| `s` | Показать главу, экран, страницу и процент |
| `l` | Перейти к номеру страницы или проценту |
| Ctrl+клик по маркеру картинки | Открыть эту иллюстрацию в отдельной вкладке (Cmd+клик на macOS; точный модификатор указан при наведении) |
| `i` | Открыть текущую иллюстрацию или выбрать, если их несколько |
| `?` | Справка по клавишам |
| Escape | Скрыть текст и показать подсказку продолжения |
| `r` (когда текст скрыт) | Продолжить чтение |
| `q` | Закрыть терминал читалки и сохранить позицию |

**VSCodeReader: Resume Reading** возвращает скрытый текст или открывает последнюю книгу после закрытия терминала или перезапуска VS Code. **VSCodeReader: Hide Text** скрывает текущую сессию через палитру команд. После Escape нажмите `r` или вызовите Resume Reading.

## Прогресс и закладки

В панели **Library** видны текущая книга, глава, экран, страница и процент. Нажмите на строку прогресса или клавишу `l` и введите страницу, например `12`, либо процент, например `40%`.

Экран зависит от размера терминала и меняется при его растягивании. Страницы текста — фиксированные отрезки примерно по 1000 символов на всю книгу; их номера не меняются от ширины и размера шрифта. Это условные страницы чтения, а не страницы печатного издания. Для CBZ показывается реальный номер страницы-картинки и их общее количество. Точный фрагмент сохраняется автоматически при навигации, скрытии, закрытии и завершении работы; повторные изменения размера сохраняют исходный текстовый якорь.

Клавиша `b` ставит быструю закладку. Кнопка **Add bookmark…** в боковой панели позволяет задать имя. Закладки появляются в **Bookmarks**: нажатие возвращает к фрагменту, кнопки карандаша и корзины позволяют переименовать и удалить. В **Recent books** остаются последние десять книг, а **Open books** позволяет переключаться между открытыми сессиями.

Позиции и закладки хранятся локально. Изменение исходного файла начинает новую позицию чтения. Содержимое книг не отправляется в сеть.

## Форматирование и таблицы

Терминал сохраняет структуру документа: заголовки выровнены по левому краю и выделяются жирным/подчёркиванием; у обычных абзацев отступ первой строки — четыре ячейки (в узкой колонке уменьшается). Отступ получает только первая видимая строка; списки, в том числе ручные и с висячим отступом, таблицы, цитаты, код, стихи, подписи и оглавление сохраняют свою вёрстку. Отступ добавляется только при отображении, без пробелов в исходном тексте, смещениях поиска или копируемом фрагменте; сохраняются жирность, курсив, подчёркивание и зачёркивание. У списков видны маркеры, номера, вложенные отступы и начальный номер. Цитаты выделяются префиксом, блоки кода и pre сохраняют пробелы и переносы.

EPUB учитывает локальные подключённые таблицы стилей и inline-стили. Поддерживаемое текстовое подмножество CSS включает селекторы тегов/классов/ID, потомков и дочерних элементов, наследование, inline-объявления, `!important`, вес/стиль/размер шрифта, подчёркивание/зачёркивание, white-space и скрытый текст. Оси переменных шрифтов `wght`, `slnt`, `ital` преобразуются в выделения терминала. Классы абзацев вроде `Heading-2` и увеличенные жирные абзацы распознаются как заголовки, в том числе в экспортах InDesign. Лимиты: 1 МиБ на таблицу стилей и 5000 суммарных правил на документ. Удалённые стили/import и файлы шрифтов не загружаются; шрифт, цвета и тема терминала остаются настройками VS Code.

Таблицы отображаются сеткой с переносами текста внутри ячеек. Если колонки получаются слишком узкими, каждая строка превращается в вертикальную карточку с подписями колонок. Сохраняются названия таблиц, пустые ячейки и позиции объединённых колонок. Рамки и подписи карточек — элементы отображения; исходные смещения используются для поиска, ссылок на изображения/сноски и позиции чтения. Смена размера меняет вёрстку, сохраняя номер текстовой страницы и точную исходную позицию. Это терминальное представление, а не браузерная CSS-вёрстка; вложенные таблицы разворачиваются в текст внешней ячейки.

## Мышь, выделение и копирование

Колёсико и тачпад прокручивают саму книгу с сохранением позиции. `v` временно отключает перехват мыши и фиксирует текст, чтобы перерисовка не сбрасывала выделение; ещё раз `v` возвращает чтение. Escape по-прежнему скрывает текст, `q` закрывает читалку. Изменение размера терминала завершает режим выделения. Shift+перетаскивание также использует стандартное выделение терминала VS Code. Копируйте его обычной комбинацией терминала своей платформы — например Ctrl+Shift+C на Linux.

`y` копирует видимый исходный фрагмент, сохраняя абзацы и отступы, без экранных переносов, полей, префиксов, подсказок и служебных маркеров изображений. Для произвольного фрагмента нажмите `Y` или **Select / copy clean text…** в Library. Текущая глава откроется около позиции чтения в обычном текстовом редакторе только для чтения, со стандартным выделением и копированием. Закрытие вкладки не требует сохранения, исходная книга не редактируется. Одновременно можно открыть до восьми разных вкладок копирования; закрытие освобождает снимок. У страниц CBZ нет текста для копирования. Расширение не читает и не переписывает уже выделенный текст терминала через буфер обмена.

## Поиск, история переходов и сноски

`/` ищет буквальный текст без учёта регистра. Текущее совпадение выделяется инверсией, остальные подчёркнуты. `[` и `]` переходят между совпадениями по кругу. В нижней строке показаны счётчик совпадений и клавиши, если хватает места; номер страницы всегда имеет приоритет. Запрос ограничен 256 символами, результаты — первыми 1000 совпадениями (`+` означает ограничение). Последний запрос хранится локально для каждой книги и восстанавливается после перезапуска. `c` очищает его и убирает подсветку.

`u` возвращает к точному месту перед переходом, `U` ведёт вперёд. В историю попадают переходы через оглавление, закладки, номер страницы или процент, смену главы, поиск и сноски. Обычная прокрутка и листание экранов сохраняют исходную точку возврата. Новый переход после возврата очищает ветку вперёд. У каждой открытой книги своя история до 100 переходов; она живёт в пределах сессии чтения. В Library также доступны **Back**, **Forward** и **Find in book…**, а в палитре — соответствующие команды.

Ctrl+клик по сноске/внутренней ссылке или `f` открывает ссылку с текущего экрана; если на экране их нет, используется список главы. Читалка переходит к цели; `u` возвращает к чтению. EPUB noteref может вести в документ пакета вне основного spine; нелинейные документы spine добавляются после основного текста. Поддерживаются ссылки FB2 на разделы примечаний и ссылки `#якорь` в HTML/Markdown. Markdown также понимает `Текст[^id]`, определение `[^id]: Текст сноски` и продолжение строками с отступом. Неизвестные якоря и внешние ссылки остаются неактивными. Сноски — часть самой книги; личные заметки и аннотации пока не реализованы.

## Изображения и комиксы

В терминале показаны нумерованные маркеры вроде `[image #1: Rabbit]`. **Ctrl+клик по маркеру** открывает именно эту иллюстрацию в отдельной вкладке (на macOS — Cmd+клик; точный модификатор VS Code показывает при наведении). Ссылка привязана к своей книге и перестаёт действовать после смены страницы, скрытия или закрытия читалки. Длинные маркеры переносятся; если фрагмент неоднозначен в очень узком терминале, используйте `i`. Клавиша `i` открывает иллюстрацию в отдельной вкладке редактора. Если в текущей главе одна картинка, она открывается сразу; иначе появляется список, в котором картинки текущей главы идут первыми. Команда **VSCodeReader: Open Image** показывает все изображения книги, включая обложки. Фокус остаётся в терминале для дальнейшей навигации.

Изображения из EPUB-архива, base64 из FB2 и иллюстрации HTML/Markdown загружаются только по запросу. Поддерживаются PNG, JPEG, GIF, WebP и BMP. SVG и удалённые изображения не открываются. Лимиты картинки: 10 МиБ, 40 мегапикселей и 16 384 пикселя по каждой стороне. Локальный кэш предпросмотра ограничен 128 файлами / 100 МиБ; после вытеснения старую иллюстрацию может потребоваться заново открыть из книги.

В HTML/Markdown пути к изображениям считаются относительно папки документа. Картинка должна оставаться внутри неё, в том числе после разрешения символических ссылок. Абсолютные пути, выход в родительскую папку и удалённые URL не открываются; HTML `<base>` и `srcset` не используются. Поддерживаются также растровые изображения `data:image/...;base64,...`. Обычные редакторы HTML/Markdown в VS Code остаются основными; для чтения вызывайте Open Book.

В CBZ выбирайте страницу клавишами `n` / `p` и открывайте её через Ctrl+клик по маркеру или `i`. Страницы остаются в отдельных вкладках; переключение страницы само по себе не открывает картинку. Если файл книги изменился, закройте её терминал и откройте книгу заново перед просмотром изображений.

## Установленная сборка и обновления

В Library всегда показано **Installed: 0.1.0 · code <ревизия>**. При наведении видны полный коммит и время сборки; щелчок или **VSCodeReader: Installed Build** позволяет скопировать ревизию. Сборки из незакоммиченных исходников помечены **local changes**, официальные сборки GitHub содержат SHA чистого коммита. Метаданные также лежат в `dist/build-info.json` внутри VSIX.

Пункт **Open latest GitHub Release** в Library или команда **VSCodeReader: Open Latest GitHub Release** открывает актуальный релиз в браузере. Сравните его ревизию с установленной, установите VSIX через `code --install-extension vscode-reader-0.1.0.vsix --force` и выполните **Developer: Reload Window**. Переход к релизу выполняется по команде; фоновых запросов обновлений нет.

## Настройки

- Шрифт, размер и цвета: обычные настройки терминала VS Code.
- `vscodeReader.terminalName`: шаблон имени вкладки, по умолчанию `{title}`. Можно использовать `{filename}`. Значение `output` также заменяется названием книги.
- `vscodeReader.wheelScrollLines`: строк на событие колёсика/тачпада, по умолчанию `3`; значение `1` даёт более мелкую прокрутку. Применяется сразу.
- `vscodeReader.maxTextWidth`: максимальная ширина текста в ячейках терминала, без префикса и полей; `0` по умолчанию использует доступную ширину.
- `vscodeReader.horizontalPadding`: минимальные поля слева и справа в ячейках, по умолчанию `0`; в узком терминале автоматически уменьшаются.
- `vscodeReader.centerText`: центрирование ограниченной по ширине колонки, по умолчанию `false`.
- `vscodeReader.linePrefix`: необязательный префикс вроде `[text] `; по умолчанию пустой.
- `vscodeReader.textEncoding`: `utf-8` по умолчанию или `windows-1251` для TXT, HTML и Markdown без BOM или объявления кодировки в HTML. BOM имеет приоритет; HTML также учитывает meta charset, а FB2 следует объявлению кодировки в XML.

**VSCodeReader: Reading Layout** предлагает всю ширину терминала, центрированные колонки на 80/100 символов и переход к своим настройкам. Ширина, поля и центрирование применяются к открытым книгам сразу, сохраняя точную позицию и номер страницы. Остальные настройки читалки применяются к новым сессиям. Для смены кодировки текста закройте и заново откройте книгу. В области чтения — текст и компактная строка подсказок; данные книги и прогресс находятся в Library.

## Разработка и проверки

```sh
npm run lint         # ESLint для TypeScript, JavaScript и скриптов релиза; без предупреждений
npm run lint:fix     # автоматические исправления линтера
npm run check        # линтер, строгий typecheck, unit-тесты, сборка расширения и parser worker
npm run test:host    # интеграционные проверки в VS Code 1.95.3
npm run package      # VSIX без samples, тестов и node_modules
npm run benchmark    # первый перенос, 1000 переходов с кэшем и 100 перерисовок
# Необязательная локальная проверка на своей отладочной EPUB:
READER_DEBUG_EPUB=/path/to/book.epub node --import tsx test/formatting.test.ts
```

Проект написан на TypeScript с VS Code API; скрипты работают на Node.js, сборка использует esbuild. ESLint проверяет рекомендуемые правила JavaScript/TypeScript, необработанные Promise, асинхронные callback и некорректный `await` с учётом типов. TypeScript дополнительно проверяет пропущенные возвраты и проваливание между ветками switch. Перед обновлением релиза GitHub Actions требует успешного `npm run check` и тестов в VS Code. Для редактора в workspace рекомендовано расширение ESLint. TypeScript закреплён на версии 6, совместимой с поддерживаемым диапазоном typescript-eslint.

Host-тест запускает VS Code дважды и проверяет восстановление позиции и именованных закладок после полного перезапуска. При первом запуске он скачивает VS Code. На Linux нужны библиотеки Electron и дисплей (в CI используется `xvfb-run`). Переменная `VSCODE_TEST_VERSION` позволяет проверить другую версию VS Code. Тесты используют синтетические книги и сохранённый EPUB, без скачивания книг.

XHTML EPUB проходит валидацию и разбор один раз на документ. Переносы рассчитываются при посещении главы; на сессию кэшируются до четырёх вариантов / 100 000 строк, а текст каждой строки создаётся только по запросу. Переходы используют двоичный поиск по смещениям строк и общий индекс позиций книги. Текущий вариант остаётся доступен и при превышении бюджета кэша. Для ASCII есть быстрый путь переноса, для Unicode сохраняется учёт графем. Бенчмарк выводит время без зависящих от компьютера порогов успешности.

Разбор и извлечение изображений выполняются в отменяемых worker. Лимиты: входной файл 100 МиБ, объявленное содержимое архива 300 МиБ, 10 000 записей, один извлекаемый ресурс 10 МиБ, прочитанный текст до 32 МиБ. Несжатые документы FB2/TXT/HTML/Markdown ограничены 32 МиБ; FB2 внутри архива — 10 МиБ.

Скрипты книг и терминальные управляющие последовательности не исполняются. HTML преобразуется в структурированный текст с терминальными стилями и таблицами; формы и динамическое содержимое страницы не отображаются. Внешние Markdown-ссылки сохраняют подписи и остаются неактивными. Полная браузерная/CSS-вёрстка, ленивое чтение глав и расширенная доступность остаются в плане. Лицензия собственного кода пока не выбрана (`UNLICENSED`); уведомления зависимостей включены в VSIX.
