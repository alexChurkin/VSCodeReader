# VSCodeReader

[English](README.md) · **Русский**

Чтение книг в VS Code во вкладке, похожей на консольный вывод. VSCodeReader использует настоящую вкладку **Terminal** с названием книги, шрифт и цвета вашего терминала, управление с клавиатуры. Иллюстрации открываются по запросу в отдельных вкладках редактора.

Текущая сборка **0.1.0** поддерживает EPUB, FictionBook, обычный текст, комиксы CBZ, HTML и Markdown. [План реализации](docs/IMPLEMENTATION_PLAN.md) · [Архитектурные решения](docs/ADR-001-terminal-reader.md).

## Поддерживаемые форматы

| Формат | Поддержка |
| --- | --- |
| EPUB 2 / EPUB 3 (`.epub`) | Текст с переносами, порядок глав spine, оглавление nav/NCX, встроенные растровые изображения |
| FictionBook 2 (`.fb2`) | Метаданные, вложенные разделы, стихи, примечания как разделы, изображения base64; кодировки из XML, включая Windows-1251 |
| FB2.ZIP / FBZ (`.fb2.zip`, `.fbz`) | Одна или несколько книг FB2; выбор книги, если в архиве их несколько |
| Обычный текст (`.txt`) | UTF-8, UTF-16 с BOM и настраиваемая Windows-1251; длинные файлы разбиваются на части для навигации |
| HTML (`.html`, `.htm`) | Заголовки как главы, название и автор документа, текст, списки, блоки кода, локальные и base64-изображения |
| Markdown (`.md`, `.markdown`) | Заголовки ATX/Setext, списки/задачи/таблицы GFM, блоки кода и изображения |
| Comic Book ZIP (`.cbz`) | Растровые страницы в естественном порядке имён (`page2` перед `page10`); клавиша `i` открывает текущую страницу |

Обычные `.zip` не считаются книгами. PDF и MOBI/AZW3 не поддерживаются. EPUB с фиксированной вёрсткой, DRM, мультимедиа и переходы по сноскам внутри текста не входят в эту версию.

## Запуск

1. Установите `vscode-reader-0.1.0.vsix` через **Extensions: Install from VSIX…**.
2. Нажмите **значок книги** на левой панели Activity Bar: откроется **Reader → Library**.
3. Нажмите **Open book…** и выберите файл. Для продолжения позже используйте **Continue reading**.

Версия остаётся **0.1.0**: каждая сборка заменяет `vscode-reader-0.1.0.vsix` и удаляет устаревшие VSIX проекта.

Для локальной сборки выполните `npm ci` и `npm run package` (Node.js 22). Для разработки нажмите F5 (`Run VSCodeReader`). Нужен VS Code 1.95.0 или новее. Для проверки есть [пример EPUB «Алисы»](samples/README.md).

Во вкладке терминала видно название книги, а в Library — список открытых книг. Настройка `vscodeReader.terminalName` позволяет задать свой шаблон с `{title}` и `{filename}`.

В контекстном меню Explorer для поддерживаемых файлов доступно действие **Open Book**. Повторное открытие той же книги возвращает её сессию. У разных книг внутри одного FB2-архива отдельные сессии и позиции чтения.

## Управление

Внизу терминала закреплена тусклая строка подсказок. Она подстраивается под ширину и показывает нужные клавиши при чтении, поиске, выборе пункта или вводе имени закладки. Справа постоянно видны текущая страница, общее число страниц и процент, например `Page 12/47 | 24.3%`. На узком терминале сокращаются подсказки и подтверждения закладок, а счётчик страниц имеет приоритет. Клавиша `?` открывает полный список действий.

Когда фокус находится в терминале читалки:

| Клавиши | Действие |
| --- | --- |
| `j` / `k`, ↓ / ↑ | Следующая / предыдущая строка |
| Space / PageDown, PageUp | Следующий / предыдущий экран с переходом между главами |
| `n` / `p` | Следующая / предыдущая глава или страница комикса |
| `g` | Оглавление |
| `/` | Поиск по книге, до 200 совпадений |
| `b` | Быстрая закладка с подтверждением сохранения |
| `B` | Перейти к закладке |
| `s` | Показать главу, экран, страницу и процент |
| `l` | Перейти к номеру страницы или проценту |
| `i` | Открыть текущую иллюстрацию или выбрать, если их несколько |
| `?` | Справка по клавишам |
| Escape | Скрыть текст и показать подсказку продолжения |
| `r` (когда текст скрыт) | Продолжить чтение |
| `q` | Закрыть терминал читалки и сохранить позицию |

**VSCodeReader: Resume Reading** возвращает скрытый текст или открывает последнюю книгу после закрытия терминала или перезапуска VS Code. **VSCodeReader: Hide Text** скрывает текущую сессию через палитру команд. После Escape нажмите `r` или вызовите Resume Reading.

## Прогресс и закладки

В панели **Library** видны текущая книга, глава, экран, страница и процент. Нажмите на строку прогресса или клавишу `l` и введите страницу, например `12`, либо процент, например `40%`.

Экран зависит от размера терминала и меняется при его растягивании. Страницы текста — фиксированные отрезки примерно по 1000 символов на всю книгу; их номера не меняются от ширины и размера шрифта. Это условные страницы чтения, а не страницы печатного издания. Для CBZ показывается реальный номер страницы-картинки и их общее количество. Точный фрагмент сохраняется автоматически при навигации, скрытии, закрытии и завершении работы; повторные изменения размера сохраняют исходный текстовый якорь.

Клавиша `b` ставит быструю закладку. Кнопка **Add bookmark…** в боковой панели позволяет задать имя. Закладки появляются в **Bookmarks**: нажатие возвращает к фрагменту, кнопки карандаша и корзины позволяют переименовать и удалить. В **Recent books** остаются последние десять книг, а **Open books** позволяет переключаться между открытыми сессиями.

Позиции и закладки хранятся локально. Изменение исходного файла начинает новую позицию чтения. Содержимое книг не отправляется в сеть.

## Изображения и комиксы

В терминале вместо картинок показаны текстовые маркеры. Клавиша `i` открывает иллюстрацию в отдельной вкладке редактора. Если в текущей главе одна картинка, она открывается сразу; иначе появляется список, в котором картинки текущей главы идут первыми. Команда **VSCodeReader: Open Image** показывает все изображения книги, включая обложки. Фокус остаётся в терминале для дальнейшей навигации.

Изображения из EPUB-архива, base64 из FB2 и иллюстрации HTML/Markdown загружаются только по запросу. Поддерживаются PNG, JPEG, GIF, WebP и BMP. SVG и удалённые изображения не открываются. Лимиты картинки: 10 МиБ, 40 мегапикселей и 16 384 пикселя по каждой стороне. Локальный кэш предпросмотра ограничен 128 файлами / 100 МиБ; после вытеснения старую иллюстрацию может потребоваться заново открыть из книги.

В HTML/Markdown пути к изображениям считаются относительно папки документа. Картинка должна оставаться внутри неё, в том числе после разрешения символических ссылок. Абсолютные пути, выход в родительскую папку и удалённые URL не открываются; HTML `<base>` и `srcset` не используются. Поддерживаются также растровые изображения `data:image/...;base64,...`. Обычные редакторы HTML/Markdown в VS Code остаются основными; для чтения вызывайте Open Book.

В CBZ выбирайте страницу клавишами `n` / `p` и открывайте её через `i`. Страницы остаются в отдельных вкладках; переключение страницы само по себе не открывает картинку. Если файл книги изменился, закройте её терминал и откройте книгу заново перед просмотром изображений.

## Настройки

- Шрифт, размер и цвета: обычные настройки терминала VS Code.
- `vscodeReader.terminalName`: шаблон имени вкладки, по умолчанию `{title}`. Можно использовать `{filename}`. Значение `output` также заменяется названием книги.
- `vscodeReader.linePrefix`: необязательный префикс вроде `[text] `; по умолчанию пустой.
- `vscodeReader.textEncoding`: `utf-8` по умолчанию или `windows-1251` для TXT, HTML и Markdown без BOM или объявления кодировки в HTML. BOM имеет приоритет; HTML также учитывает meta charset, а FB2 следует объявлению кодировки в XML.

Настройки читалки применяются к новым сессиям. Для смены кодировки текста закройте и заново откройте книгу. В области чтения — текст и компактная строка подсказок; данные книги и прогресс находятся в Library.

## Разработка и проверки

```sh
npm run check        # typecheck, unit-тесты, сборка расширения и parser worker
npm run test:host    # интеграционные проверки в VS Code 1.95.3
npm run package      # VSIX без samples, тестов и node_modules
```

Host-тест запускает VS Code дважды и проверяет восстановление позиции и именованных закладок после полного перезапуска. При первом запуске он скачивает VS Code. На Linux нужны библиотеки Electron и дисплей (в CI используется `xvfb-run`). Переменная `VSCODE_TEST_VERSION` позволяет проверить другую версию VS Code. Тесты используют синтетические книги и сохранённый EPUB, без скачивания книг.

Разбор и извлечение изображений выполняются в отменяемых worker. Лимиты: входной файл 100 МиБ, объявленное содержимое архива 300 МиБ, 10 000 записей, один извлекаемый ресурс 10 МиБ, прочитанный текст до 32 МиБ. Несжатые документы FB2/TXT/HTML/Markdown ограничены 32 МиБ; FB2 внутри архива — 10 МиБ.

Скрипты книг и терминальные управляющие последовательности не исполняются. HTML преобразуется в текст; CSS, формы и динамическое содержимое страницы не отображаются. От Markdown-ссылок остаются подписи без интерактивных переходов. Полная HTML-вёрстка, ленивое чтение глав, интерактивные сноски и расширенная доступность остаются в плане. Лицензия собственного кода пока не выбрана (`UNLICENSED`); уведомления зависимостей включены в VSIX.
