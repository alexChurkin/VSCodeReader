# VSCodeReader

Планируемое расширение VS Code для чтения EPUB и FictionBook 2 во вкладке Terminal. Основной режим выглядит как обычный консольный вывод: моноширинный текст, цвета терминала и управление с клавиатуры.

Реализация ещё не начата. [План разработки](docs/IMPLEMENTATION_PLAN.md) описывает MVP, архитектуру, дополнительные форматы, этапы и критерии готовности.

Для первого прототипа добавлен [пример EPUB](samples/README.md) из Project Gutenberg.
